Markdown 语法一览

这篇文章覆盖 mksite 内置引擎支持的所有语法，可以直接当写作模板用。

行内元素

粗体、斜体、行内代码、删除线，以及链接 和图片 ![alt](src)。HTML 会被自动转义：<script> 永远不会被执行。

引用

零依赖意味着：一个 Python 解释器 + 一个包，就是全部运行环境。

嵌套引用也没问题。

列表

无序列表支持嵌套：

  • 静态站点生成
    • Markdown 渲染
    • 模板变量
  • 开发服务器
  • RSS / sitemap

有序列表（起始编号不是 1 也可以）：

  1. 第三名
  2. 第四名

代码块

from mksite.markdown import md_to_html

html = md_to_html("# Hello, **mksite**!")
print(html)  # <h1 id="hello-mksite">Hello, <strong>mksite</strong>!</h1>

表格支持按列对齐：

命令作用备注
mksite init初始化站点必备
mksite build构建静态文件必备
mksite serve本地预览可选
mksite new新建文章可选
